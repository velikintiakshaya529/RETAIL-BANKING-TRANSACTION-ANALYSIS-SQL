# 🏦 RETAIL BANKING TRANSACTION ANALYSIS USING SQL

## 📌 PROJECT OVERVIEW

This project focuses on analyzing retail banking data using SQL to generate meaningful business insights related to customers, accounts, transactions, branches, loans, loan payments, and cards.

The project was completed as part of my Data Analytics learning journey at **Innomatics Research Labs**.

## 🎯 PROJECT OBJECTIVE

The objective of this project is to use SQL to analyze banking data and answer important business questions that can support data-driven decision-making.
