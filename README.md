# 🏦 RETAIL BANKING TRANSACTION ANALYSIS USING SQL

## 📌 PROJECT OVERVIEW

This project focuses on analyzing **retail banking data using SQL** to uncover meaningful business insights related to customers, accounts, transactions, branches, loans, loan payments, and cards.

The project was completed as part of my **Data Analytics learning journey at Innomatics Research Labs**, with a focus on applying SQL concepts to a real-world banking business scenario.

---

## 🎯 PROJECT OBJECTIVE

The main objective of this project is to analyze banking data and answer important business questions that can help organizations:

* Understand customer behavior
* Monitor account and transaction activity
* Analyze loan performance
* Identify customer engagement patterns
* Evaluate branch-level performance
* Support data-driven business decisions

---

## 💼 BUSINESS PROBLEM

Retail banks generate large volumes of customer, account, transaction, loan, and card data.

The challenge is to transform this raw data into useful information that can help the bank understand:

* Who are the most active customers?
* Which branches perform better?
* What types of transactions are most common?
* Which customers have loans?
* How are loans and payments performing?
* Which customers are inactive?
* How can customer engagement be improved?

SQL was used to explore these questions and generate actionable insights.
